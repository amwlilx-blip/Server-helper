# Server Builder 2.0 — Rust • Русский

## Возможности
- `/setup` — создать недостающие категории, каналы и роли Rust.
- `/settings` — интерактивная панель: тикеты, временные голосовые, приглашение ботов, приветствие, канал логов.
- `/ticket-panel` — опубликовать панель тикетов в текущем канале.
- `/voice-setup` — назначить текущий голосовой канал лобби создания комнат.
- `/bot-invite` — сформировать OAuth2-ссылку приглашения стороннего бота.
- `/ban`, `/kick`, `/mute`, `/warn`, `/clear` — базовая модерация.

## Установка (Windows)
1. Распакуйте архив в папку проекта.
2. Откройте CMD в этой папке и выполните `npm install`.
3. Скопируйте `.env.example` в `.env` и заполните DISCORD_TOKEN, CLIENT_ID, GUILD_ID.
4. В Developer Portal → OAuth2 URL Generator добавьте scopes `bot` и `applications.commands`. Для Server Builder выдайте: Manage Channels, Manage Roles, View Channels, Send Messages, Read Message History, Move Members, Connect, Send Messages, Manage Messages, Moderate Members, Kick Members, Ban Members.
5. В Developer Portal → Bot включите Server Members Intent, если используете приветствия. Для временных комнат нужен Guild Voice States intent (он включён в коде).
6. Зарегистрируйте команды: `npm run deploy`.
7. Запустите: `npm start`.
8. В Discord выполните `/setup`, подтвердите. Затем `/settings`.

## Настройка функций
- Тикеты: `/settings` → «Опубликовать панель тикетов». Пользователь нажимает кнопку, получает приватный канал; автор или администратор может закрыть его.
- Временные комнаты: `/settings` → «Назначить текущий голосовой канал лобби» (администратор должен находиться в голосовом канале). Пользователь входит в лобби, бот создаёт комнату с его отображаемым именем и переносит его туда. Пустая комната удаляется.
- Приглашение других ботов: `/settings` → соответствующий пункт либо `/bot-invite`. Бот формирует ссылку OAuth2; подтвердить установку должен администратор. Настройка внутреннего функционала стороннего бота доступна только если у него есть собственная API/панель.
- Приветствия: `/settings` → «Настроить приветствие», укажите ID текстового канала и текст. `{user}` заменяется упоминанием нового участника.
- Логи: `/settings` → «Назначить канал логов», выберите настройку, находясь в нужном текстовом канале. Модераторские команды отправляют туда записи.

## Важные ограничения и безопасность
- Не передавайте DISCORD_TOKEN никому и не публикуйте `.env`.
- Команды модерации требуют соответствующих прав у вызывающего пользователя и у бота. Роль бота должна быть выше ролей, которыми он управляет.
- Приглашение стороннего бота не обходится без подтверждения администратора сервера.
- Для приветствий включите Server Members Intent в Developer Portal и добавьте `GuildMembers` intent в код, если ваша конфигурация discord.js/портала этого требует.
- Сторонний бот не может быть принудительно настроен из Server Builder: можно управлять его приглашением, ролями и разрешениями; его собственные команды/функции настраиваются через его интерфейс.
- Тикеты в этой версии удаляются после закрытия; экспорт/транскрипт тикетов пока не реализован.
- `src/data.json` создаётся автоматически и хранит настройки сервера локально.
